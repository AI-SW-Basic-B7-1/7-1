# B7-1 웹 기반 AI 챗봇 프로젝트 요약

**담당자 검토용 · 2026-09-23**

## 프로젝트 개요

로그인한 사용자가 웹 화면에서 AI와 대화하고, 대화 문맥과 이력을 확인할 수 있는 웹 챗봇 프로토타입입니다. 사용자 인증, 서버 측 AI API 호출, 대화 기록의 SQLite 저장, 오류 처리와 운영 로그를 하나의 서비스 흐름으로 연결하는 것을 목표로 합니다.

## 구조

```text
브라우저 (HTML/CSS/JavaScript)
        │ REST API
        ▼
FastAPI ─ 인증(JWT) · 채팅 API · 입력 검증 · 로깅
        ├── Gemini API (비동기 호출, 타임아웃 처리)
        └── SQLite (사용자 · 대화방 · 대화 기록)

배포 구성: AWS EC2 · Nginx · Uvicorn/Systemd
```

## 주요 기능과 구현 현황

- 회원가입·로그인, 비밀번호 해싱, JWT 기반 인증 및 인증되지 않은 채팅 요청 차단
- 질문을 Gemini API에 서버 측에서 전달하고, 같은 대화방의 최근 대화 이력을 문맥으로 구성
- 사용자별 대화방·대화 기록 저장 및 본인 이력 조회
- 공백 질문과 길이 초과 입력 검증, AI 타임아웃·호출 오류 처리
- 요청 수신, AI 호출, 응답 성공, DB 저장 성공·실패 로그 기록
- 프론트엔드, 인증·채팅·DB·AI 테스트 코드, DB 및 배포 확인 스크립트와 문서 보유

저장소에는 각 기능의 코드와 테스트 파일, EC2 배포 절차가 있습니다. 코드·문서 검토만으로 테스트 통과나 현재 배포 사이트의 정상 동작을 단정하지 않으며, 해당 결과는 별도 실행 증빙으로 확인할 예정입니다.

## 계획과 진행도

계획은 4일 일정으로 독립 모듈/API 계약 설정 → 인증·채팅 기능 및 프론트엔드 연동 → 실제 AI·DB 통합 → 예외 처리·로그·배포 점검 순서입니다. 저장소 이력에는 2026년 9월 22일까지 PR 병합 기록이 있으며, 현재 코드에는 인증·채팅·DB·AI·UI 및 배포 관련 산출물이 포함되어 있습니다. 완료 여부는 실제 시연, 테스트 결과, 배포 상태를 기준으로 최종 확인할 필요가 있습니다.
