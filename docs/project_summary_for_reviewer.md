# 반려동물 동반 국내여행 AI 챗봇 검토 요약

**작업 기준: 2026-10-07, `develop`의 `4c67c8` 기반 작업 브랜치**

## 서비스 목표

반려동물과 국내여행을 준비하는 사용자가 여행 조건과 동반 가능 여부를 확인하도록 돕는 웹 서비스를 목표로 합니다. 현재 저장소는 로그인·대화방·채팅 기록·Gemini 연동을 갖춘 챗봇을 기반으로 여행 기능을 확장하는 단계입니다.

## 현재 구현과 후속 범위

- 회원가입·로그인과 JWT 인증을 제공합니다.
- 질문을 Gemini API에 전달하고, 대화방별 문맥과 질문·응답 기록을 SQLite에 저장합니다.
- 요청 로깅, 예외 처리, 프론트엔드 및 백엔드 자동화 테스트 코드가 있습니다.
- Gemini가 검색 조건을 추출하고 KorPetTourService2의 장소·반려동물 상세 정보를 조회해 근거 기반 답변을 생성합니다. 지역별 관광 자원 수요, Google Maps, 장소 카드와 구조화된 응답은 아직 구현되지 않았습니다.

## 요청·배포 흐름

브라우저 요청은 Nginx에서 FastAPI로 전달됩니다. EC2에서는 `/static/` 요청도 FastAPI로 프록시하며 FastAPI가 정적 파일을 제공합니다. PR #64는 배포 스크립트에 `Asia/Seoul` 시간대 설정·확인과 CSS·JavaScript 정적 파일 응답 검사를 추가합니다.

## 확인 경계

이 문서는 `develop`의 `4c67c8`을 기준으로 한 작업 브랜치의 변경 상태를 설명하며, 아직 원격 `develop`에 반영되었다는 뜻은 아닙니다. 코드와 테스트 파일의 존재만으로 현재 EC2 배포 상태를 단정하지 않습니다. 외부 API 키를 이용한 실제 서비스 동작은 별도 실행 근거로 확인해야 합니다. 배포 절차는 [EC2 배포 매뉴얼](ec2_deployment_manual.md)을 참고합니다.
