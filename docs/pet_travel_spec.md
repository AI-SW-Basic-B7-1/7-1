# 반려동물 국내여행 서비스 후속 명세

> 상태: **설계·후속 개발 기준, 미구현**. 2026-09-23 `develop`의 `755e7e2`에는 관광공사 두 서비스·Google Maps 조회/SDK/설정/테스트가 없습니다.
> 기존 FastAPI·Gemini·SQLite·Vanilla JS와 [현재 API](api_spec.md)를 우선합니다. 이 문서 PR은 기능 구현이나 유료 설정 승인이 아닙니다.

## 1. 사용자 문제와 완료 모습

반려동물 보호자가 국내여행 장소와 동반 조건을 대화로 확인하도록 돕습니다. 사용자는 로그인 후 지역·일정·종/크기 등 필요한 조건을 제공하고, 출처가 있는 후보와 미확인 조건을 받습니다. 같은 방의 후속 질문과 재로그인 후 기록 조회를 유지합니다.

타깃은 반려동물을 기르는 전 연령 사용자입니다. 첫 시연은 구체적인 지역·반려동물 조건으로 한정해 검증합니다. 예약·결제·실시간 입장 보장·모든 동물의 시설 이용 보장·접근성 검증 완료를 약속하지 않습니다.

2026-09-23 공식 소개·정책 페이지를 재확인했습니다. 키를 이용한 실제 조회와 활용 매뉴얼의 필드 매핑은 미수행이며 PoC 산출물로 남겨야 합니다.

## 3. 단계 A — 반려동물 데이터 PoC와 서버 결합

### PoC 산출물

- 활용 승인·최신 서비스 버전·목록/상세 조회 오퍼레이션을 공식 활용 명세와 실제 응답으로 확정합니다. 서비스 이름만 보고 엔드포인트를 추측하지 않습니다.
- 지역/위치 기반 검색, 페이지 처리, 장소 식별자와 상세 조회 연결을 검증합니다.
- 합성 사용자 조건으로 조회한 공개 장소의 필드명·타입·누락 여부를 기록합니다. 인증키가 들어간 요청 URL이나 개인 대화는 증빙에서 제거합니다.
- 아래 내부 계약 후보를 실제 필드에 매핑하고 없는 정보는 `미확인`으로 남깁니다. 출처 갱신시각이 없으면 조회시각으로 대체 표기하지 않고 각각 구분합니다.

| 내부 정보 후보 | 근거·처리 기준 |
|---|---|
| 원천 서비스명/장소 ID | 원천 식별자 유지, Google Place ID와 분리 |
| 장소명/주소/지역 | 응답 근거만 사용, 이름만 같은 장소를 자동 병합하지 않음 |
| 위도/경도 | 원천 좌표계·순서·범위 검증 후 변환, AI 생성 금지 |
| 동반 허용/종/크기/실내외 제한 | 실제 제공 필드·조건 문구에 연결, 누락을 허용으로 해석하지 않음 |
| 주의사항/이용 시설 | 검증한 정보만 표시 |
| 출처/원천 갱신시점/조회시점 | 독립 보존, 현재 방문 전 재확인 안내 |

### 서버 접점

인증 및 방 소유권 확인 → 같은 방 문맥/조건 확인 → 관광 조회 → 확인한 근거와 사용자 질문을 Gemini에 전달 → 답변/필요한 출처 저장 → 응답 순서로 설계합니다. 기존 5쌍 문맥과 전체 이력 조회를 혼동하지 않습니다. 조회 근거는 외부 데이터로 취급하고 그 안의 지시문을 시스템 규칙으로 실행하지 않습니다.

`generate_chat_response(question, history)`에 근거 인자를 추가한다면 AI 담당·채팅 담당이 호출부·대역·테스트를 같은 기능 PR에서 변경합니다. 관광 API와 AI 각각의 타임아웃, 총 대기시간, 불필요한 재시도 방지, 요청 식별자와 실패 원인 로그를 설계합니다. 키/토큰/개인 질문 전체를 운영 로그에 추가하지 않습니다.

조회 실패 또는 결과 없음이면 확인된 장소가 없다는 사실과 조건 변경/재시도 안내를 제공합니다. 일반적인 준비 안내를 제공하더라도 실제 조회 기반 추천처럼 표시하지 않습니다. AI·DB 실패의 502/504/500 및 롤백 의미는 유지합니다.

## 4. 단계 B — 지역별 관광 자원 수요

관광 서비스 수요와 문화 자원 수요를 지역 비교의 보조 정보로 연결합니다. PoC에서 원천 지역 코드·공간 단위·기준 기간·지표 정의·단위·결측 표현을 확인하고 별도의 지역 매핑표를 작성합니다. 서로 다른 서비스의 코드가 같다고 가정하지 않습니다.

- 같은 기준으로 비교할 수 있는 지역/기간/단위만 비교합니다. 기간 불일치·결측은 비교 불가로 남기고 0으로 채우지 않습니다.
- 수요 값이나 실제 응답에 없는 일별 추이·예측·실시간 혼잡도를 생성하지 않습니다.
- 순위가 필요하면 비교 집합·기간·정렬 방향·계산식을 공개합니다. 사전 근거 없는 가중치나 점수는 확정하지 않습니다.
- 사용자 조건 및 동반 근거를 우선 적용하고, 지역 비교를 원하는 경우 수요를 보조 설명으로 제공합니다.
- 수요 장애가 있어도 확인된 반려동물 장소 안내와 기본 대화가 가능하도록 합니다.

증빙에는 매핑 예, 원천 응답과 설명의 대조, 누락/기간 불일치/서비스 실패의 기대 동작을 포함합니다.

## 5. 단계 C — Google Maps

| 제품 후보 | 선택 기준 |
|---|---|
| Maps JavaScript API | 여러 장소·지도·마커와 상호작용을 위한 우선 후보 |
| Maps Embed API | 단일 장소 등 단순 삽입으로 충분할 때 검토 |
| Places API | 장소 검색/상세 보완이 필요할 때만 별도 채택 |
| Routes API | 국내 이동수단별 실제 지원·품질 PoC 후 경로가 필요한 경우 검토 |
| Maps URLs | 키 없이 외부 지도를 여는 링크. API 연결 완료로 세지 않음 |

2026-09-23 [공식 지원 표](https://developers.google.com/maps/coverage)의 한국 행은 차량·도보 경로에 `—`(미제공 또는 낮은 품질/가용성)를 표시합니다. 지도 표시와 경로 계산을 별도 검증하고 국내 길찾기·이동시간을 기본 제공으로 약속하지 않습니다. [Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)는 대체 링크 후보이며 SDK 지도와 구분합니다.

### 응답·DB·화면 접점

현행 `ChatResponse`에는 장소 배열이 없습니다. 구조화된 장소/좌표/출처 전달을 기존 응답의 호환 확장으로 할지 별도 보호 API로 할지 기능 PR에서 결정합니다. 해당 결정에는 이력 응답·DB 저장 또는 재조회 전략·재로그인 복원·원천 이용 조건을 포함합니다. 구체 테이블이나 엔드포인트는 아직 확정하지 않습니다.

- 자유문장 `answer`에서 좌표를 정규식으로 뽑거나 AI가 좌표를 만드는 방식을 사용하지 않습니다.
- 좌표가 검증된 장소만 마커로 표시하고, 좌표 누락 시 이름/주소/동반 조건의 텍스트 대안을 제공합니다.
- 계정 변경·방 선택·새 대화·늦은 응답에서 지도/장소/지역 수요 상태가 섞이지 않아야 합니다. 현재 `viewGeneration`·토큰 대조와 접합합니다.
- SDK 로드/키 제한/네트워크 실패가 텍스트 답변·이력·로그인을 막지 않게 합니다. 지도 없이도 장소 정보를 읽을 수 있어야 합니다.
- 외부 SDK 도입 시 현재 동일 출처 자원 테스트에 필요한 공식 SDK 호스트만 허용하도록 계약을 수정합니다. 기존 인증·상태 격리·API 검증은 유지합니다.
- 채팅 문장은 계속 안전한 텍스트로 렌더링하고 별도 장소 카드의 링크도 허용된 URL 형식을 검증합니다. 전 연령 사용자를 위해 키보드·작은 화면·읽기 순서를 검사합니다.

## 6. 설정·키·데이터 정책

다음은 **현재 코드가 읽지 않는 설정 후보**입니다. `.env.example`에 현행 필수 설정으로 추가하지 않습니다. 실제 제품·승인·동작이 확정된 기능 PR에서 이름·기본값·필수 여부를 결정합니다.

| 후보 | 용도 |
|---|---|
| `TOUR_API_KEY`, `TOUR_API_BASE_URL`, `TOUR_API_TIMEOUT_SECONDS` | 반려동물 데이터 서버 조회 |
| `TOUR_DEMAND_API_KEY`, `TOUR_DEMAND_API_BASE_URL`, `TOUR_DEMAND_API_TIMEOUT_SECONDS` | 지역 수요 서버 조회. 서비스별 승인과 키 공유 가능 여부 확인 |
| `GOOGLE_MAPS_BROWSER_API_KEY` | 브라우저 지도 SDK용 제한 키 |
| `GOOGLE_MAPS_MAP_ID` | 선택한 지도 기능에 필요할 때 |
| `GOOGLE_MAPS_SERVER_API_KEY` | 서버 REST API를 추가 채택할 때만 검토 |

Gemini·관광공사·Google 서버용 키는 서버 전용입니다. 브라우저 SDK 키는 사용자에게 보일 수 있으므로 Git 밖에서 주입하고 허용 웹사이트·API 제한을 적용합니다. 서버 키와 분리하며 모든 키를 브라우저에서 숨길 수 있다고 설명하지 않습니다. [Google 키 보안 지침](https://developers.google.com/maps/api-security-best-practices)을 따릅니다.

선택 제품의 [요금·할당량](https://developers.google.com/maps/documentation/javascript/usage-and-billing)을 확인하고 예상 사용량·제한·장애 동작을 남깁니다. 예산 알림은 자동 과금 차단이 아닙니다. 유료 프로젝트 설정·키 발급은 이 문서 작업에 포함되지 않습니다.

출처 표기·허용 저장기간·캐시·생성 모델 입력에 제공할 수 있는 범위를 제품별로 확인합니다. 특히 [Places 정책](https://developers.google.com/maps/documentation/places/web-service/policies)을 확인하기 전 원문 전체의 무제한 영구 저장이나 Gemini 전송을 기본 설계로 확정하지 않습니다.

## 7. 인수 기준

| 상황 | 기대 동작·증빙 |
|---|---|
| 장소 조회 성공 | 원천 필드와 안내 내용·좌표·출처 대조 |
| 결과 없음/조건 누락 | 빈 결과·미확인 안내, 허위 시설/동반 규정 없음 |
| 원천 간 내용 충돌 | 출처·갱신시점·확인 필요 항목 구분 |
| 관광/수요 인증·할당량·타임아웃 | 오류 원인 구분, 비밀값 없는 로그, 사용자 안내, 다음 정상 요청 처리 |
| 수요 결측·기간 불일치 | 비교 불가 표시, 임의 0/순위 없음, 기본 채팅 유지 |
| 좌표/ID 누락 | 장소 자동 동일시 없이 텍스트 대안 |
| 지도 SDK/키/네트워크 오류 | 텍스트·대화 이력 유지 |
| AI·DB 실패 | 기존 오류 의미·저장 롤백, 실패 후 정상 요청 |
| 계정/방 전환·늦은 응답 | 이전 상태 유출 없음 |
| 재로그인/재접속 | 합의한 장소·출처 복원 계약 확인 |

대역 단위·계약 테스트와 실 API 결과를 따로 기록합니다. 실 조회 시점·환경·배포 SHA·사용한 제품·허용된 공개 응답 예·실패 복구 결과가 있어야 해당 기능을 완료로 표시합니다. 지도는 SDK로 실제 표시한 결과와 외부 링크만 연 결과를 구별합니다.
