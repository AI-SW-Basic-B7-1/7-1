# 관광 후보 확대와 토큰·호출 비용 모델

기존 검색은 첫 페이지 5건을 모두 상세 조회하여 같은 조건의 장소가 반복되기 쉬웠습니다. 현행 코드는 첫 페이지 후보 20건 안에서 최대 5건을 선택합니다. 답변을 길게 늘리거나 장소를 지어내는 방식 대신, 실제 데이터의 추천 선택 폭을 넓힙니다.

프론트 파일, `ChatRequest`·`ChatResponse`, 인증, 대화방 소유권 검사, 대화 DB 스키마, 최근 5쌍 조회·저장, EC2 배포 설정을 유지합니다. 라우터는 내부 관광 함수에 현재 질문·이미 권한 확인된 대화 이력·분석된 목적지 시군구 조건을 전달합니다. 변경은 `AI-SW-Basic-B7-1/7-1`의 작업 브랜치에서만 수행합니다.

## 비용 계산의 범위

`scripts/model_pet_tour_cost.py`는 서비스의 후보 수·선택 수·캐시 시간을 사용하여 외부 호출 없이 비교합니다. 입력 토큰·출력 토큰은 사용자가 지정하는 가정 또는 측정값입니다. 문자 수를 토큰 수로 환산하지 않으며, 가정값을 실제 측정으로 표현하지 않습니다.

```bash
venv/bin/python scripts/model_pet_tour_cost.py
```

기본 가정은 질문 100건 중 80건에 광역 지역·유형이 명확하고, 분석 호출당 입력 2,200·출력 64토큰, 최종 답변 호출당 입력 3,400·출력 1,400토큰입니다. 최종 답변 입력에는 지침·최근 5쌍·관광 상세정보·현재 질문을 모두 포함합니다. 출력에는 생각 토큰도 합산합니다. 최종 답변 길이를 줄였다고 가정하지 않습니다.

| 비교 항목 | 기존 | 개선 가정 |
| --- | ---: | ---: |
| Gemini 생성 호출 | 200회 | 120회 |
| 입력 토큰 합계 | 560,000 | 384,000 |
| 출력·생각 토큰 합계 | 146,400 | 141,280 |
| Gemini 유료 표준 비용 | $0.5340 | $0.4684 |
| 관광 API, 매 요청 캐시가 비어 있음 | 최대 1,100회 | 최대 1,120회 |
| 관광 API, 동일 20개 후보·캐시 유효 | 최대 1,100회 | 시군구 없음 최대 41회·있음 최대 42회 |

이 가정에서 Gemini 입력은 31.4%, 생성 호출은 40%, 금액은 약 12.3% 줄어듭니다. 직접 판별 성공이 0건이면 Gemini 호출·금액은 기존과 같습니다. 로컬 판별은 모르는 지명이나 이동 표현을 포함한 질문을 Gemini로 넘기므로 직접 판별 성공 비율은 실측으로 교체해야 합니다. 분석 단계의 목적지·시군구 지침과 JSON 필드가 늘어난 만큼 실제 단계별 토큰 값도 재계측해야 합니다. 실제 상세정보와 대화 길이에 따라 최종 입력 토큰이 늘어날 수도 있습니다. 조건을 잘못 전달하지 않도록 상세 조건과 대화 이력을 임의로 잘라 비용을 줄이지 않습니다.

광역 질문의 관광 호출 상한은 11회이며 시군구가 확인된 질문만 최대 12회입니다. 로컬 판별 80건은 시군구 조회가 없고 나머지 20건에서만 조회가 추가될 수 있으므로, 예시의 캐시 없는 호출 상한은 `100 × 11 + 20 = 1,120`회입니다. 새로운 지역·유형·시군구를 계속 묻거나 캐시를 유지하지 못하면 관광 호출 절약은 없습니다.

42회는 시군구 코드 1회 + 목록 1회 + 20개 장소의 두 상세 조회를 모두 합친 상한입니다. 시군구가 없으면 코드 조회를 하지 않아 41회입니다. 이 관광 반복 조회 시나리오는 위 Gemini 호출 비율 계산과 별개이며, 단일 프로세스, 동일 검색 조건, 순차 실행, 전체 요청이 첫 조회부터 300초 안에 끝나고 캐시 퇴출·시군구 조회 장애가 없는 상황에 한정합니다. 동시 최초 요청, 프로세스 재시작·증설, 캐시 만료, 다른 조건을 섞거나 시군구 조회를 실패한 경우에는 이 상한을 적용할 수 없습니다. 시군구 실패는 캐시하지 않아 다음 요청에서 재조회하며 후보의 주소를 확인해 목적지 범위를 유지합니다. 이미 선택할 장소까지 모두 캐시된 요청의 관광 호출은 0회입니다.

가격은 2026-10-08 확인한 `gemini-3.5-flash-lite` 유료 Standard 텍스트 기준 입력 100만 토큰당 $0.30, 출력·생각 100만 토큰당 $2.50입니다. [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite)를 기준으로 하며 가격·모델 변경 시 인자로 갱신합니다. 무료 요금제의 토큰 청구액은 0일 수 있으나 요청·토큰 할당량은 별도입니다. 환율·세금·EC2·선택적 Jev shadow 비용은 포함하지 않습니다.

관광 API는 [공공데이터포털 공식 안내](https://www.data.go.kr/data/15135102/openapi.do)상 무료입니다. 호출 감소는 유료 토큰 비용과 분리해 관광 API 트래픽 할당량 절약으로 표시합니다.

## 실측으로 가정값 교체

Gemini 응답의 `usageMetadata`가 있으면 `ai_token_usage` 이벤트에 모델·단계(`phase=parameters` 또는 `answer`)·입력·출력·생각 토큰 수를 기록합니다. 질문·답변·키·원본 URL은 기록하지 않습니다. 기존 필수 이벤트도 유지합니다.

```text
INFO ai_token_usage model=gemini-3.5-flash-lite phase=answer prompt_tokens=120 output_tokens=80 thoughts_tokens=10
```

분석 단계와 최종 답변 단계의 실제 평균을 각각 구해 명령행 인자로 전달합니다. 출력 토큰 인자에는 `output_tokens + thoughts_tokens`를 넣습니다. 입력·출력 값은 두 단계가 섞이지 않은 계측으로 계산해야 합니다. 단일 로그 예시는 두 단계 전체 사용량이나 품질 증빙이 아닙니다.

```bash
venv/bin/python scripts/model_pet_tour_cost.py --requests 100 --local-hits 80 --parameter-input-tokens 2200 --parameter-output-tokens 64 --answer-input-tokens 3400 --answer-output-tokens 1400 --input-price 0.30 --output-price 2.50
```

실제 요금은 [Gemini 토큰 계측 문서](https://ai.google.dev/gemini-api/docs/tokens)의 응답 메타데이터와 계정 청구를 확인해야 합니다. 이 PR은 실제 키를 사용해 유료 호출하거나 운영 DB·배포를 변경하지 않습니다.

## 무결성 검증

외부 API 대역으로 후보 20건·상세 5건 상한, 공식 시군구 필터, 최근 추천 제외, 후속 조건 질문, 캐시 만료·상한·키 변경·복사 격리, 오류 재조회, 검색 조건별 캐시 분리를 검증합니다. 실제 `POST /api/chat → 관광 조회 → Gemini → SQLite 저장 → GET /api/me/chats` 경로도 대역으로 검증하고, 다른 사용자의 대화방 요청이 외부 호출 전에 차단되는지 확인합니다.

기존 데이터 없는 장소 생성 금지, 상세 조건 부재·충돌 안내, 502·504 경계와 인증·입력 검증을 유지합니다. 실제 관광 데이터의 추천 적합도·Gemini 답변 품질·운영 캐시 효과는 대역 테스트만으로 입증하지 않습니다.
