# 반려동물 동반 정보 조회

`app/pet_service.py`는 `KorPetTourService2`의 지역별 목록을 조회한 뒤
선택한 장소의 `contentid`로 소개정보와 반려동물 상세정보를 연결합니다.

1. `areaCode2`: 광역 지역의 공식 시군구 이름·코드를 최대 100건 조회합니다. 현재 질문의 시군구를 우선하고, 없으면 최근 사용자 질문에서 확인합니다. 현재 질문에 광역 지역이 명시되거나 시군구가 여러 개면 이전 시군구를 강제하지 않습니다.
2. `areaBasedList2`: 지역·관광 유형과 확인된 `sigunguCode`로 후보를 최대 20건 조회합니다(`numOfRows=20`, 첫 페이지, 수정일순).
3. 서버에서 중복 ID를 제거하고 최대 5건을 선택합니다. 동등 후보는 무작위 순서로 선택하고, "다른 식당 추천" 등 추가 추천 요청은 최근 답변에 나온 장소를 우선 제외합니다. 후속 조건 질문은 방금 안내한 장소를 우선합니다.
4. 선택한 장소에만 `detailIntro2`·`detailPetTour2`를 호출하고, 두 상세 응답의 기존 조건·충돌 정보를 모두 Gemini에 전달합니다.

후보군을 넓히지만 한 답변의 장소 수는 최대 5개로 유지합니다. 반려동물 크기·이동장·테라스 조건은 상세 데이터에 근거해 Gemini가 설명하며, 서버의 후보 선택 자체가 동반 가능 판정을 뜻하지 않습니다.

지역과 관광 유형이 현재 질문에서 각각 하나로 명시된 경우(`서울 음식점 추천` 등)는 `app/ai_service.py`가 직접 검색 조건을 판별합니다. 이 경로는 최종 답변 생성에 Gemini를 1회 호출합니다. 시군구만 명시한 질문, 조건 누락, 여러 지역·유형, 문맥 의존 질문은 기존 Gemini 조건 분석을 사용하여 총 2회 호출합니다. 최종 답변에는 기존 최근 5쌍의 대화 이력을 그대로 전달합니다.

검색 조건 누락, 조회 결과 없음, 조회 성공에 따라 기존 Gemini 답변 지침을
사용합니다. 각 최종 답변 프롬프트는 현재 형식을 유지하고 굵게 강조하는
Markdown 장식을 사용하지 않도록 지시합니다.

공식 명세상 `chkpet`은 관광지용입니다. 문화시설·레포츠·쇼핑은 각각
`chkpetculture`, `chkpetleports`, `chkpetshopping`을 사용합니다.
음식점·숙박에는 이 필드가 없어 `detailPetTour2`의 정보를 활용해야 합니다.
동반유형코드는 의미를 추정하지 않고 원문으로 전달합니다.

반려동물 상세 조회 `detailPetTour2`의 `03`(데이터 없음)은 시설 확인 안내로
처리합니다. 소개정보 `detailIntro2`의 빈 결과는 조회 오류로 처리합니다.
인증 오류·시간 초과·잘못된 응답은 정보 부재로 숨기지 않고 기존
라우터의 오류 처리로 전달합니다. 서로 상충하는 안내는 AI에 둘 다 제공하고
시설 확인을 권하도록 지시합니다. 기존 질문·답변 저장 구조를 유지합니다.

공개 관광 응답은 프로세스 메모리에 300초 동안 최대 256개 저장합니다. 지역·유형·시군구·엔드포인트·인증키별로 분리하며, 키 원문·사용자 질문·사용자 답변은 캐시하지 않습니다. 캐시 복사본을 반환해 호출자가 원본을 변경할 수 없게 하고, 오류·잘못된 응답은 캐시하지 않습니다. 인증키가 없으면 기존 캐시를 사용하지 않습니다.

캐시가 비어 있는 채팅의 관광 API 호출 상한은 시군구 1회 + 목록 1회 + 상세 10회 = 12회입니다. 선택된 장소까지 캐시된 요청은 관광 API를 호출하지 않습니다. 지역·유형·시군구가 같은 20개 후보를 순차적으로 이용하고 캐시 만료·퇴출이 없다면 전체 호출 상한은 42회입니다. 시군구 조회를 하지 않는 기존 2인자 서비스 호출은 최대 11회입니다.

캐시는 재시작 시 없어지며 여러 프로세스에서 공유되지 않습니다. 동시 최초 요청은 중복 조회할 수 있습니다. 조건 변경이 반영되기까지 최대 5분 걸릴 수 있으므로 방문 전 시설에 확인해야 합니다. SQLite 캐시 테이블이나 마이그레이션을 추가하지 않았습니다. 각 HTTP 요청 기본 타임아웃은 기존 `PET_TOUR_API_TIMEOUT_SECONDS=15.0`초를 유지합니다.

첫 페이지의 20건 안에서만 다양화합니다. 전체 관광 DB 수집, 다음 페이지 자동 조회, 임의 시군구명 추론, 장소 자체의 무작위 생성은 수행하지 않습니다. 모든 후보를 이미 안내했거나 데이터가 적으면 일부 추천이 반복될 수 있습니다. 특정 장소가 현재 후보군 밖에 있는 후속 조회는 지원하지 않습니다.

```bash
venv/bin/python -m pytest tests/test_pet_service.py tests/test_ai_service.py tests/test_chat_router.py tests/test_pet_tour_cost.py -q
```

테스트는 외부 통신 대역을 사용합니다. 실제 키 설정 후 부산 관광지·서울 음식점의
상세 값과 최종 답변을 비교하는 검증은 별도로 필요합니다. [비용 모델](pet_tour_cost_model.md)은 가정에 따른 계산이며 실제 API 품질·청구 검증과 구분합니다. 요청 URL에는 인증키가
포함되므로 원본 URL이나 키를 로그·PR에 첨부하지 않습니다.
