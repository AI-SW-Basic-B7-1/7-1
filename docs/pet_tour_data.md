# 반려동물 동반 정보 조회

`app/pet_service.py`는 `KorPetTourService2`의 지역별 목록을 조회한 뒤
각 장소의 `contentid`로 소개정보와 반려동물 상세정보를 연결합니다.

1. `areaBasedList2`: 지역·관광 유형에 맞는 장소를 최대 5건 조회합니다(`numOfRows=5`, 첫 페이지).
2. `detailIntro2`: 관광 유형별 문의·시간·주차·기존 동반 안내를 조회합니다.
3. `detailPetTour2`: 동반 가능 동물·필요사항·시설·유의사항을 조회합니다.
4. 두 상세 응답을 같은 장소의 AI 입력 문맥에 포함합니다.

검색 조건 누락, 조회 결과 없음, 조회 성공에 따라 기존 Gemini 답변 지침을
사용합니다. 각 최종 답변 프롬프트는 현재 형식을 유지하고 굵게 강조하는
Markdown 장식을 사용하지 않도록 지시합니다.

공식 명세상 `chkpet`은 관광지용입니다. 문화시설·레포츠·쇼핑은 각각
`chkpetculture`, `chkpetleports`, `chkpetshopping`을 사용합니다.
음식점·숙박에는 이 필드가 없어 `detailPetTour2`의 정보를 활용해야 합니다.
동반유형코드는 의미를 추정하지 않고 원문으로 전달합니다.

정상적인 상세 결과 부재나 상세 조회의 `03`(데이터 없음)은 시설 확인 안내로
처리합니다. 인증 오류·시간 초과·잘못된 응답은 정보 부재로 숨기지 않고 기존
라우터의 오류 처리로 전달합니다. 서로 상충하는 안내는 AI에 둘 다 제공하고
시설 확인을 권하도록 지시합니다. 상세정보는 별도로 DB에 저장하지 않으며
기존 질문·답변 저장 구조를 유지합니다.

`_request()`가 세 오퍼레이션에 `numOfRows=5`를 설정합니다. 목록은 첫 페이지만
조회하므로 목록 결과는 최대 5건입니다. 목록 1회와 장소별 상세 2회로 요청당
최대 11회 호출합니다. 각 HTTP 요청 기본 타임아웃은 `PET_TOUR_API_TIMEOUT_SECONDS=15.0`초입니다. 캐시는 없으며,
기존 방식보다 장소별 호출이 1회 늘어납니다.

```bash
venv/bin/python -m pytest tests/test_pet_service.py tests/test_ai_service.py tests/test_chat_router.py -q
```

테스트는 외부 통신 대역을 사용합니다. 실제 키 설정 후 부산 관광지·서울 음식점의
상세 값과 최종 답변을 비교하는 검증은 별도로 필요합니다. 요청 URL에는 인증키가
포함되므로 원본 URL이나 키를 로그·PR에 첨부하지 않습니다.
